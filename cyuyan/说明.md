# C语言知识网页

按《新编C语言程序设计》（第2版，钱雪忠等，清华大学出版社）排：一章分成各小节，最后是章末期末与等考提升。页面框架、数据格式、复习功能和高数网页（`gaoshu/说明.md`）完全相同，**照抄 `gaoshu/说明.md`**；这里只写和高数不同的地方。

## 内容规则的变化（2026-10-21 定）

- 出一节前，先看教材本节 + 辅导书对应实验 + 辅导书习题参考解答，按教材和辅导书实际的例题、练习出内容，**不查考研资料**。
- 例题代码卡：`signal` 看到什么样的题会想到这个写法；`example.q` 题目或要写的小程序描述，`example.src` 出处（教材/辅导书 第几章 第几页）；`idea.key`+`idea.how` 通用写法（不针对例题本身，例如"数组求最大值的标准写法"）；`first` 第一步怎么想；`steps` 完整代码或分步讲解；`pitfall` 这类题常见错误；`practice` 练习题出处（教材习题/辅导书习题/等级考试题）。
- 代码一律能实际编译运行（`gcc -Wall -Wextra -std=c17`），写进页面前自己跑一遍，不能编译的不写进去。
- 公式最少用；位运算、地址计算等偶尔需要时写成行内代码 `‹x & 1›`，不用数学公式。
- 例题的 `example.q` 可以直接放代码块；`practice` 也走 `md()`，可以写行内代码。程序要完整可编译（带 `#include` 和 `main`），写完用 gcc 实测输出，教材里 VC++ 结果和 gcc 不同的地方要在页面里标出来。
- 页码一律用印刷页（教材 PDF 页 = 印刷页 + 14；辅导书 PDF 页 = 印刷页 + 7，见 `教材索引.md`）。
- 章末"期末与等考提升"只放：教材小结+习题里没覆盖全的、辅导书测试卷（期末考试卷A/B 最贴近本校考法）、全国计算机等级考试二级 C 语言大纲里覆盖但教材没细讲的点（如常见库函数、运算符优先级表）。**不放考研向内容**。

## 页面结构和数据格式（2026-10-29 定）

每节四块：知识框架、知识点、**题型卡**、易错点；节标题下面一行「真题考法」（`exam` 字段，写 2014–2018 江南大学期末卷里本节怎么考）。章末页：真题考法、本章例题对照表（`exampleMap`）、期末与等考提升（`points`/`types`/`pitfalls`，可以为空）、本章真题（`mixed`，标签和说明用 `mixedLabel`、`mixedNote`）。

题型卡分四种，用 `kind` 字段标在卡片标题前：

| kind | 用途 | 专用字段 |
|---|---|---|
| 读程序 | 推运行结果 | `output`（gcc 实测输出，背面才显示）、`input`（标准输入）、`trace: {cols, rows}`（逐步表格，背面「下一步 / 全部显示」逐行揭开） |
| 填空 | 程序填空 | 代码里写 `【1】【2】`；`blanks: [{a, why}]` 逐空揭开；`output` 是填好后的输出 |
| 辨析 | 选择、判断、改错 | `choices: [{s, ok, why}]` 逐项给对错和理由；改错题写在 `steps` |
| 编程 | 纸上编程 | 完整程序放在 `steps` 的代码块里（背面标「答案」）；`score: []` 评分点 |

通用字段：`nocheck: "原因"`（不实测，比如判断题、改错题原程序、依赖编译器的结果）；`tag: "拓"`。背面顺序：第一步、追踪表、输出、各空、选项、答案/步骤、评分点、易错、练习。

正文标记：`==关键词==` 高亮，`!!易错!!` 红字提醒，`**加粗**`；行内代码 `‹x›` 里的内容不参与这些标记。线索文件 `数据/线索.js`：每个知识点一条 `c`，每条补充一条 `n`。

## 内容安排（2026-10-29 定）

- 教材每道例题都要上网页，按考法改成题型卡（读程序、填空、编程）；用 rand() 的例题换成固定数据；Win-TC 画图、Windows 计时这类和考试无关的例题不做，在例题对照表里写明原因。

## 学习用法和复习规则（2026-10-30，JC-0032）

和高数相同：今日、自评和间隔复习打通、做完模式、题型卡分层 `level`、内容冻结、错题只有一个入口，规则见 `gaoshu/说明.md`「学习用法和复习规则」。C 语言的不同：

- 做完模式计时 3 分钟；读程序题先在纸上写出输出，填空题写出每一空，编程题手写完整代码。
- 分层：`期末` 是往年卷考过的、教材例题和习题里有的；`拔高` 是等级考试大纲里的拓展点。拓展题照旧标 `tag: "拓"`。
- 错题区改成和高数一样，题目放 `数据/错题.js`（字段见 `gaoshu/说明.md`「往错题区加一道题」，代码写法同数据文件：行内 ‹x›、代码块 ~~~c）。错因用 C语言项目的六类：语法、概念不清、执行过程推错、边界遗漏、算法思路、粗心。2026-10-30 已把学习仓库 C语言-错题本.md 里的 E1–E9、E11 迁进来（错题 1–10）；以后不再往 Markdown 错题本里加。
- 内容冻结：第 8 章起等课上讲到再出。

## 检查和发布

```
node cyuyan/工具/lint.js cyuyan/数据/第1章-第N节.js
node cyuyan/工具/check-cues.js
node cyuyan/工具/check-code.js            # 不写文件名就查全部节和章末
```

三个都输出「问题 0」才能提交。check-code 用 `gcc -std=c17` 编译每张题型卡的程序（编程卡取 `steps` 里含 main 的代码块，填空卡先把答案填回 `【n】`），用 `input` 运行并和 `output` 比对；带 `nocheck` 的跳过。lint 检查加粗标点规则、`~~~`（或三个反引号）围栏是否成对、`‹›` 数量是否相等（C 语言版不依赖 KaTeX，不装 `katex` 包也能跑）。

发布流程同高数：推 `main` 自动部署，再同步到学习仓库 `进度库/交互网页/C语言/`（备份）。
