# C语言知识网页

按《新编C语言程序设计》（第2版，钱雪忠等，清华大学出版社）排：一章分成各小节，最后是章末期末与等考提升。页面框架、数据格式、复习功能和高数网页（`gaoshu/说明.md`）完全相同，**照抄 `gaoshu/说明.md`**；这里只写和高数不同的地方。

## 和高数不同的地方

| 项目 | 高数 | C语言 |

| 教材 | 同济第八版上册（数学概念+解题套路） | 《新编C语言程序设计》第2版（正文）+《...实验与学习辅导》第2版（配套辅导书），两本章号一一对应，见 `D:\vscode workspace\C\教材索引.md` |
| 每节内容块 | 知识框架、知识点、题型卡、易错点 | 知识框架、知识点、**题型梳理**、易错点（2026-10-28 起标签名和高数统一为「题型梳理」，原名「例题代码」）。字段同高数：`example.q` 放题目/代码，`example.src` 放出处，`idea` 是通用写法，`think`/`first`/`steps`/`pitfall`/`practice` 同高数 |

## 内容规则的变化（2026-10-21 定）

- 出一节前，先看教材本节 + 辅导书对应实验 + 辅导书习题参考解答，按教材和辅导书实际的例题、练习出内容，**不查考研资料**。
- 题型卡：`signal` 看到什么样的题会想到这个写法；`example.q` 题目或要写的小程序描述，`example.src` 出处（教材/辅导书 第几章 第几页）；`idea.key`+`idea.how` 通用写法（不针对例题本身，例如"数组求最大值的标准写法"）；`think` 思路（为什么这样想，单列一栏，在背面最上面）；`first` 第一步怎么想；`steps` 完整代码或分步讲解；`pitfall` 这类题常见错误；`practice` 练习题出处（教材习题/辅导书习题/等级考试题）。
- 代码一律能实际编译运行（`gcc -Wall -Wextra -std=c17`），写进页面前自己跑一遍，不能编译的不写进去。
- 公式最少用；位运算、地址计算等偶尔需要时写成行内代码 `‹x & 1›`，不用数学公式。
- 例题的 `example.q` 可以直接放代码块；`practice` 也走 `md()`，可以写行内代码。程序要完整可编译（带 `#include` 和 `main`），写完用 gcc 实测输出，教材里 VC++ 结果和 gcc 不同的地方要在页面里标出来。
- 页码一律用印刷页（教材 PDF 页 = 印刷页 + 14；辅导书 PDF 页 = 印刷页 + 7，见 `教材索引.md`）。
- 章末"期末与等考提升"只放：教材小结+习题里没覆盖全的、辅导书测试卷（期末考试卷A/B 最贴近本校考法）、全国计算机等级考试二级 C 语言大纲里覆盖但教材没细讲的点（如常见库函数、运算符优先级表）。**不放考研向内容**。

## 两本书都要管（2026-10-28 恆定）

- 每节、每章章末都同时参考教材《新编C语言程序设计》第2版和辅导书《C语言程序设计 实验与学习辅导》第2版，`sources` 两本都列；哪本没有对应内容就在页面上写明「辅导书无对应」。
- 两本书上的例题、书后习题、辅导书实验里的程序填空和改错，**每一道都要在网页里讲透**（计划每章加一页「书上题清单」）。

## 往错题区加一道题（2026-10-28）

做法同 `gaoshu/说明.md`「往错题区加一道题」：录进 `数据/错题.js`，提交到 `main` 就上线，不需要令牌。不同处只有两点：

- `cause` 用 C 语言的六类：语法、概念不清、执行过程推错、边界遗漏、算法思路、粗心。
- 代码写成 `~~~c ... ~~~` 或 `‹x›`，先用 gcc 实测；考试按 VC++ 6.0 答，结果不同时两个都写。

检查：`node cyuyan/工具/lint.js cyuyan/数据/错题.js` 输出「问题 0」再提交。旧方式 `records/cyuyan/wrong.json` 仍兼容，同编号以数据文件为准。

## 检查和发布

```
node cyuyan/工具/lint.js cyuyan/数据/第1章-第N节.js
node cyuyan/工具/check-cues.js
```

两个都输出「问题 0」才能提交。lint 检查加粗标点规则、`~~~`（或三个反引号）围栏是否成对、`‹›` 数量是否相等（C 语言版不依赖 KaTeX，不装 `katex` 包也能跑）。

发布流程同高数：推 `main` 自动部署，再同步到学习仓库 `进度库/交互网页/C语言/`（备份）。
