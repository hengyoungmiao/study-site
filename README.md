# records 分支

各科知识网页的个人记录，由网页自动提交，不含网页代码。网页站点在 `main` 分支；这个分支只放数据，用于复盘。

| 科目 | 文件夹 | 网页 |
|---|---|---|
| 高等数学 | `records/` | `/gaoshu/` |
| 线性代数 | `records/xiandai/` | `/xiandai/` |

每个文件夹里：

- `state.json`：自评（marks）、间隔复习（srs）、☆ 和 △（stars）、我的总结（notes）。
- `wrong.json`：错题区的题目，由克整理后提交。
- `review.md`：每次同步后自动生成的复盘摘要，克复盘时读它。

两科分开存，是因为条目键都是「节号/条目号」（如 `1.1/p1`），放在一起会互相覆盖。
