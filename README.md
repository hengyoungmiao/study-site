# study-site

恆的学习网站。纯静态，没有构建步骤，部署在 Cloudflare Workers 静态资源（`wrangler.jsonc` 里 `assets.directory` 是仓库根目录），推送到 `main` 后自动部署。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 首页（以后改成个人主页） |
| `gaoshu/index.html` | 高数知识网页的页面框架 |
| `gaoshu/数据/` | 每节一个数据文件（`第N章-第M节.js`，章末 `第N章-章末.js`）；`我的总结.js` 是预置的「✎ 总结」；`线索.js` 是线索自测的手写线索 |
| `gaoshu/工具/` | `lint.js` 检查公式和加粗，`check-cues.js` 检查每条知识点都有线索 |
| `gaoshu/依赖/` | 公式排版用的 KaTeX，字体已内嵌 |
| `gaoshu/说明.md` | 怎么加一节、数据格式、同步和复盘、建站与维护规则 |

## 高数知识网页现有内容

第 1 章 10 节加章末考研提升、第 2 章第 1 节。每节四块：知识框架、知识点、题型卡、易错点。

页面功能：

- ☆ 不熟、△ 重点记录、✓ ✗ 自评（可取消）、✎ 总结（自己的话）。
- 知识点页的「线索自测」：每条知识点和补充都有手写线索，正文模糊，点击显示。
- 复习中心：薄弱清单、速认、限时抽题、间隔复习（1、3、7、21 天）。
- 错题区，错题和知识点、题型互相跳转。
- 全站搜索；侧边栏可折叠的本节大纲；手机上目录是从左滑出的抽屉。

## 分支和记录

- `main`：网页本身。
- `records`：个人记录，由网页和克提交，不和 `main` 合并。`records/state.json` 是合并后的原始记录，`records/review.md` 是自动生成的复盘摘要（克复盘时读它），`records/wrong.json` 是错题。
- 每台设备在页面「记录」里填一次 GitHub 令牌（Fine-grained token，只选本仓库，Contents 读写），之后多端自动同步。令牌只放在浏览器里，不写进代码和仓库。详见 `gaoshu/说明.md`。
- 没填令牌时，记录只存在浏览器 localStorage（键 `gaoshu-kb-v1`），换域名会是空的，可以用页面右上角「记录」复制、导入。

## 改动之前

- 加一节：按 `gaoshu/说明.md` 的「加一节」做，写完跑 `node gaoshu/工具/lint.js <数据文件>` 和 `node gaoshu/工具/check-cues.js`，都没有问题再提交。需要 `npm i katex`。
- 本仓库是网页的标准版本；学习仓库 `进度库/交互网页/高等数学/` 是备份，每次更新后同步。
- 改页面行为、数据格式、内容规则，先和恆确认。
