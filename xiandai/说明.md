# 线性代数知识网页

**固定规矩（2026-10-27，恆定）：线代网页一律按 `gaoshu/` 里最新的高数网页格式编写**——页面框架（`index.html`）、数据文件格式、题型卡的呈现（正面「看到、例题」、通法、背面「思路、第一步、解答、易错、出处和练习」）、三色标记、错题区，全部和高数保持一致。高数网页以后有新格式，线代跟着改；新增或修改线代网页前，先对照 `gaoshu/说明.md` 和 `gaoshu/` 里最新一节。`xiandai/index.html` 和 `gaoshu/index.html` 除了科目专属的几处（标题、目录 `CATALOG`、数据文件列表 `DATA_FILES`、记录键、`records/xiandai/` 路径、「复盘记录」标题、借用高数令牌）以外必须一致。

按学校教材《线性代数》排：一章分成各小节，最后是章末考研难度提升。页面框架、数据格式、复习功能和高数网页完全相同，**照抄 `gaoshu/说明.md`**；这里只写和高数不同的地方。

## 和高数不同的地方

| 项目 | 高数 | 线代 |
|---|---|---|
| 教材 | 同济第八版上册 | 学校教材《线性代数》（先矩阵、后行列式；仓库里目前只有第 1 章） |
| 本机记录键 | `gaoshu-kb-v1` | `xiandai-kb-v1` |
| 同步配置键 | `gaoshu-sync-v1` | `xiandai-sync-v1`；没填时自动借用 `gaoshu-sync-v1` 的令牌 |
| records 分支里的文件夹 | `records/` | `records/xiandai/`（`state.json`、`wrong.json`、`review.md`） |
| 新设备快捷配置 | `网址/gaoshu/#setup=令牌` | `网址/xiandai/#setup=令牌` |
| 吉米多维奇 | 题型参考，题型卡里排在最前 | 可选参考（2026-10-21 恆定），见下 |

两科条目键都是「节号/条目号」（如 `1.1/p1`），所以记录必须分文件夹存，不能共用一个 `state.json`。

## 内容规则的变化（2026-10-21，恆定）

- 线代题型卡以 30讲、李永乐的题型为主；**吉米多维奇从必查改为可选**，手边有书时再补「题型参考」的题号。
- 题型顺序：教材里有的题型在前（教材正文例题和练习题覆盖的），只在考研书里出现的在后，标「研」。
- 例题优先选教材、30讲 的题，写出处。
- 其余规则（知识框架、知识点、易错点、线索、公式写法、网页上不标「⚠️未核验」、计算先用代码验算）和高数相同。

## 数据格式和标记（照高数，2026-10-27 起）

- 题型卡：`signal` 看到、`example` 例题、`idea`（`key`、`how`、`refs`）、`think` 思路（可选，放背面）、`first` 第一步、`steps` 解答、`pitfall` 易错、`practice` 练习。**`steps` 每一步以 `++这一步做什么++` 开头**（不再用 `**标签**：`），原来写在第一步的「思路」单独放进 `think`。
- 三种标记（和高数相同）：`==关键词==` 黄底；`++步骤动作句++` 蓝字；`!!易错提醒!!` 红字红底。由克逐条阅读后手工标，不能插进 `$...$` 里面。
- 错题区 `数据/错题.js`，录入方法同 `gaoshu/说明.md`「往错题区加一道题」；线代错题的 `links` 用线代的节号，如 `["1.4/p8","1.4/t4"]`。
- 工具：`工具/lint.js`（检查公式、加粗和三种标记）、`工具/check-cues.js`、`工具/dump.js`（按行号列出一节要读的内容）、`工具/apply-marks.js`（按清单批量加标记），和高数相同。

## 学习用法和复习规则（2026-10-30，JC-0032）

和高数完全相同：今日、自评和间隔复习打通、做完模式（计时 5 分钟）、题型卡分层 `level`、内容冻结、错题只有一个入口。规则见 `gaoshu/说明.md`「学习用法和复习规则」。

## 页码

页码一律写印刷页。各本书转换稿里页码标记 `<!-- PDF第N页 · 印刷页M -->` 的位置不一样（2026-10-21 核对）：

| 书 | 标记位置 | 意思 |
|---|---|---|
| 教材、30讲 | 每页开头 | 标记**后面**的内容属于印刷页 M |
| 9讲、李永乐、1000题 | 每页末尾 | 标记**前面**的内容属于印刷页 M |

教材转换稿识别错误多（例如 1.2 节性质 1.6(3) 被识别成「≠」），公式以纸质书为准。

```
node xiandai/工具/lint.js xiandai/数据/第1章-第N节.js     # 公式、加粗、三种标记
node xiandai/工具/check-cues.js
```

两个都输出问题 0 才能提交。发布流程同高数：推 `main` 自动部署，再同步到学习仓库 `进度库/交互网页/线性代数/`（备份）。
